# Writing an assessment

1. Create a new file in this folder named: `YYYY-MM-DD-short-title.md`
   (e.g. `2026-09-14-flax-typhoon-ttp-shift.md`)

2. Start the file with a single title line, then write the rest in
   plain markdown:

3. Commit and push it. The `Build Assessments` GitHub Action will
   automatically render it into its own page and add it to the
   Assessments tab on the site within a minute or two.
